## Опис
TattooAI Studio --- це вебзастосунок для тату-студії, який допомагає клієнтам знайти свого майстра та візуалізувати ідею майбутнього татуювання. Головна мета --- спростити комунікацію між клієнтом та тату-майстром на етапі розробки ескізу за допомогою штучного інтелекту.

## Ролі
- **Гість:** може переглядати каталог майстрів, їхні портфоліо, доступні стилі та загальну інформацію про студію.
- **Користувач (Клієнт):** може генерувати чорнові ескізи за допомогою AI-інструменту, зберігати їх у своєму профілі та надсилати запит обраному майстру на доопрацювання та запис на сеанс.
- **Тату-майстер:** має доступ до панелі запитів, де бачить надіслані клієнтами AI-ескізи, описи ідей та може керувати власним портфоліо.
- **Адміністратор:** керує списком майстрів, стилями, записами та контентом платформи.

## Основний функціонал
- Каталог майстрів із фільтрацією за стилями та переглядом їхніх робіт.
- Реєстрація, авторизація та управління профілем (JWT-аутентифікація).
- Формування заявки на тату-сеанс із прикріпленням референсів та згенерованих ескізів.
- Особистий кабінет для майстра з історією запитів від клієнтів.
- REST API на базі Django REST Framework та збереження даних у реляційній базі.

## Особливість проєкту
Інтеграція з генеративним AI API (Gemini API, бо безкоштовний) для створення приблизного ескізу татуювання за текстовим описом клієнта. Це вирішує проблему «не знаю, як пояснити» і дає майстру візуальну базу для розуміння задуму клієнта перед розробкою фінального індивідуального дизайну.
